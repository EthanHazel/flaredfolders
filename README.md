# WORK IN PROGRESS

This branch is currently in alpha! Do not expect complete documentation.

## Features

### Customization Options

- Set folder style
  - Windows 11
  - Windows 11 Box
  - Icon Only
- Change colors of the background
  - Includes gradients, solid colors, and original color
- Add custom icons
  - Lucide
  - SimpleIcons
  - Custom Upload

### Export Formats

| Format | Support                                |
| ------ | -------------------------------------- |
| `.ICO` | Native Windows Use                     |
| `.PNG` | Specific sized icon                    |
| `.ZIP` | Package containing all sizes as `.png` |
